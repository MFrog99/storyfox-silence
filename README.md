# StoryFox Silence

Приложение для медитаций под Android и Windows: 23 техники (дыхание, осознанность, расслабление, сердце, сон, фокус), голосовые подсказки, поющие чаши, звуки природы и музыка из Яндекс Музыки.

## Готовые файлы

| Файл | Платформа |
|---|---|
| `dist/StoryFoxSilence-Setup.exe` | Установщик для Windows 10/11 (x64) |
| `dist/StoryFoxSilence.apk` | Android 7.0+ (64-битные устройства) |

## Возможности

- **Техники.** Квадратное дыхание, 4-7-8, когерентное дыхание, Нади Шодхана, физиологический вздох, сканирование тела, метта, мышечная релаксация, «Безопасное место», медитация горы, «Со-Хам», тратака, практика перед сном, тихое сидение с интервальным колоколом и другие.
- **Сессия.** Шар следует за фазами дыхания, вокруг идёт кольцо прогресса. Подсказки озвучиваются, в начале и в конце звучит колокол. Можно поставить на паузу, начать заново и отметить самочувствие после практики.
- **Звуки природы.** Дождь, океан, лес, ветер, космос и коричневый шум синтезируются прямо в приложении, без звуковых файлов.
- **Яндекс Музыка.** Вход по коду на `ya.ru/device`. Поиск, «Мне нравится» и ваши плейлисты. Треки можно собирать в свои наборы («Для сна», «Утро» и т. д.) и выбирать набор фоном для любой практики.
- **Прогресс.** Серия дней, минуты, график за неделю, история, любимая практика.
- **Темы.** Тёмная, светлая или как в системе. Стиль взят из проекта «Тишина»: шрифты Lora и Manrope, палитра шалфей/песок/лаванда/глина.

> Без подписки Яндекс Плюс Яндекс отдаёт только 30-секундные фрагменты треков. Это ограничение сервиса.

## Устройство проекта

```
web/            общий интерфейс (HTML/CSS/JS) для обеих платформ
core/           ym_service.py — Python-сервис: Яндекс Музыка + хранилище
vendor/         библиотека yandex-music (MarshalX, LGPL-3.0)
desktop/        Windows-оболочка на pywebview (Edge WebView2)
android/        Android-оболочка: WebView + Chaquopy (Python внутри APK)
installer/      скрипт установщика Inno Setup
tools/          генерация иконок
```

Интерфейс обращается к нативной части через `Native.call(method, ...args)` (`web/js/bridge.js`).
- **Windows:** вызов идёт в `pywebview.api.call`.
- **Android:** вызов идёт в `AndroidBridge.call`.

В обоих случаях дальше вызывается `ym_service.dispatch()`. Одна и та же библиотека yandex-music работает на обеих платформах.

## Сборка

Нужны Python 3.12 и JDK 17+.

**Windows** (нужен Inno Setup 6 или 7):

```bash
powershell -ExecutionPolicy Bypass -File build_windows.ps1
```

**Android** (нужен Android SDK с platform 34; путь задаётся в `android/local.properties`):

```bash
cd android && gradlew.bat assembleRelease
```

Готовый APK: `android/app/build/outputs/apk/release/app-release.apk`.

## Ключ подписи Android

APK подписан ключом `android/keystore/release.jks`, пароль лежит в `android/keystore.properties`. **Сохраните оба файла.** Без них не получится выпустить обновление, которое установится поверх текущей версии. Не публикуйте их.

## Данные

- **Windows:** `%APPDATA%\StoryFox Silence\storage.json`.
- **Android:** внутреннее хранилище приложения.

В этом файле лежат настройки, наборы треков, история и токен Яндекса.
